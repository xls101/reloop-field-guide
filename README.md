# ReLoop — a local-first less-waste field guide

Original static Web app with no account, API key, analytics or production dependencies. It supports local image preview (never image recognition), explicit material confirmation, practical three-step guidance, transparent carbon scenarios, local history and offline reports.

## Complete source and tests

`SOURCE.zip` contains the complete original module source, 75 unit tests, safe local server/build scripts, manual-only Pages workflow and minimal public EPA/NIST evidence necessary to reproduce numeric-reference checks. It excludes credentials, private user files, browser/runtime caches and unrelated projects. Unpack it into a fresh folder to run:

```sh
npm test
npm start
npm run build
```

No npm install is required. The public Web app's source is also readable directly through index.html, app.js, styles.css, lib/ and assets/. The source archive uses ES modules (`type: module`) with `.js` script/test names.

## Evidence and honest boundaries

75/75 local unit tests and29/29 real Edge browser cases passed. Static whitelist build passed. Original exact reports/screenshots remain in the local review package; this is not a claim of remote CI until a remote run is actually observed.

EPA WARM v16 (December2023) supplies two explicitly selected production references: container glass0.53/0.60 and identified PET resin2.17/2.21 MTCO2e/US short ton. NIST conversion is907.1847kg/US short ton. These are current-mix/virgin alternatives, not confidence intervals, measured/net/marginal savings or current supplier-specific footprints. PET excludes bottle forming, cap and label. Mass, displacement, prices and costs remain assumptions. Without a published water factor, source water is Not modelled.

See METHODOLOGY.md and SOURCE_CITATIONS.md for exact URLs, boundaries and hashes.
